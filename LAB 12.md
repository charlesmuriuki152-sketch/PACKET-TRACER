## Overview
This project demonstrates routing between different networks using Cisco Packet Tracer, covering router configuration, IP addressing, routing tables, and network connectivity.

## Objectives
- Configure IP addresses on network devices.
- Connect networks using routers and switches.
- Understand routing tables and packet forwarding.
- Test connectivity between devices on different networks.
- Develop practical networking skills for CCNA and cybersecurity.

## Tools Used
- Cisco Packet Tracer
- Routers, switches, and PCs
- Command-Line Interface (CLI)
