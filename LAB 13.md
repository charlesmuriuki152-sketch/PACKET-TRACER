# Cisco Packet Tracer: Observe Web Requests

## 1. Overview

This lab explores how a client communicates with a web server when requesting a webpage. Using Cisco Packet Tracer, I observed DNS resolution, HTTP requests, and TCP traffic between the client and server.

## 2. Objectives

* Verify connectivity using `ping`.
* Understand DNS name resolution.
* Observe HTTP requests and responses.
* Examine HTML code hosted on a web server.
* Analyze TCP and HTTP traffic in Simulation Mode.

## 4. Key Observations

* **DNS:** Resolves a domain name into an IP address.
* **HTTP:** Enables the client to request and receive webpages.
* **TCP:** Provides reliable, ordered data delivery.
* **Simulation Mode:** Visualizes packet flow and network events.
* **HTML:** Defines the structure and content of a webpage.
