## 📚 Repository Contents

### 🧪 Networking Labs

The `Labs` folder contains practical exercises and lab instructions covering different networking topics.

The repository includes activities related to:

- Building a home network
- Communication principles
- Network media and access layers
- IPv4 addressing and network segmentation
- IPv6 addressing
- Dynamic addressing using DHCP
- Network address translation (NAT)
- Address Resolution Protocol (ARP)
- Routing between networks
- TCP and UDP
- Application layer services
- Network testing and troubleshooting
- Wireless networking and network security

*The topics available depend on the individual lab files in this repository.*

### 🖥️ Cisco Packet Tracer Activities

The repository also contains `.pka` activity files that can be downloaded and opened using Cisco Packet Tracer.

These activities help practise network configuration, connectivity testing, and troubleshooting in a simulated environment.

### 📄 Documentation

Markdown (`.md`) files provide lab instructions, explanations, procedures, and learning notes to accompany the practical exercises.

## 🚀 Getting Started

Follow these steps to explore the repository.

1. **Browse the labs:** Open the `Labs` folder and select an exercise.
2. **Read the instructions:** Open the corresponding Markdown file.
3. **Download the activity:** Find the relevant `.pka` file in the repository.
4. **Open Packet Tracer:** Launch Cisco Packet Tracer on your computer.
5. **Complete the exercise:** Follow the lab instructions and test your configuration.
6. **Troubleshoot:** Use appropriate networking commands to investigate any connectivity issues.

### Requirements

- A computer running a compatible version of Cisco Packet Tracer.
- Basic familiarity with computer networking.
- Access to the lab instructions and activity files in this repository.
